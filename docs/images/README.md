# Image provenance

`before-16x9-bars.jpg` and `after-native-21x9.jpg` are user-captured Elden Ring
gameplay frames from the verified CrossOver ultrawide test.

`elden-ring-banner-source.webp` is the text-free Elden Ring image supplied by
the repository owner for the project banner. `social-preview.png` uses that
exact source. Processing was limited to a 2:1 crop, resize, tonal adjustment,
a readability gradient and typography. No AI-generated or synthetic game
imagery was used.

The images are included only to document and illustrate compatibility and
aspect-ratio behavior. Elden Ring and its visual assets belong to their
respective rights holders.
