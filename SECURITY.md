# Security policy

This project never distributes or requests `eldenring.exe`, save files, Steam
credentials, cookies, account databases, or CrossOver bottle archives.

When reporting a compatibility problem, share the game version, the SHA-256 of
the clean executable, CrossOver/macOS versions, and the launcher log. Never
upload the executable itself. Report security issues privately through GitHub's
security-advisory feature when it is available for the repository.
