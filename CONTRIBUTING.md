# Contributing

Bug reports and verified patch profiles are welcome. Before opening an issue:

1. use Steam's **Verify integrity of game files** command;
2. run `scripts/diagnose.command`;
3. record the Elden Ring, CrossOver, and macOS versions; and
4. include hashes and logs only—never upload game executables, save files, or
   Steam account data.

Changes to a patch offset must include reproducible evidence from a clean Steam
executable and must preserve the launcher's fail-closed signature validation.
